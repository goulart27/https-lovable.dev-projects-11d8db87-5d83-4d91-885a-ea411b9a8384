# CyberMedieval Shield

Jogo educativo multiplayer medieval cyberpunk para IA, Segurança Cibernética, Redes, Vulnerabilidades, Linux, Endpoints e Cisco.

Inclui lobby, quiz níveis 1 a 5, XP, recompensas, arena níveis 6 a 10, HP, Curandeira, presença multiplayer via Supabase Realtime e persistência.

Para Supabase: execute supabase/schema.sql, configure a URL e a chave anon no ambiente de hospedagem e habilite Realtime/Presence.

Próximas evoluções: autenticação por sala, estado de batalha sincronizado, movimentação isométrica, ataques, turnos transacionais, leaderboard agregado e sons.
